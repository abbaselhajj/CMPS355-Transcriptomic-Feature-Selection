# Public release checklist

- [x] Original method implementations included (Python, R, shell runners and tests)
- [x] Notebook output cells and execution counts preserved without edits
- [x] Original LOCO method signatures, final V2 native selected genes and vote evidence included
- [x] Main five-method aggregate results, Jaccard and pathway tables included
- [x] Final manuscript source/PDF, editable vector figures and bibliography included
- [x] Manifest and evidence checker included
- [x] Patient-level predicted probabilities, large raw data and RDS files excluded
- [ ] **Repository created on GitHub** and uploaded by the authors
- [ ] **URL inserted into manuscript** after the GitHub repository has been created
- [ ] Independent full retraining from a fresh clone (requires external data/R packages; not claimed)

The public snapshot is evidence of executed analysis, not a claim of fully push-button model retraining.
